# Sanket AI identity

The approved **Signal S** combines two opposing evidence paths into a single initial. The construction uses two filled contours, equal 48-unit weights, 76-unit outside radii and 28-unit inside radii on a 256-unit canvas. It has no strokes, filters, embedded images or font dependencies.

## Files

- `../../frontend/public/logo.svg`: teal symbol master.
- `../../frontend/public/logo-horizontal.svg`: Figtree wordmark converted to vector outlines.
- `logo-stacked.svg`: stacked outlined lockup.
- `../../frontend/public/favicon.svg`: lime symbol on a navy tile.
- `exports/`: black, white, teal and lime variants, plus transparent 512 px PNG symbols.
- `concepts-v1.png`: three initial directions, reviewed before the user selected A.
- `concept-a-v1.svg`, `concept-a-v2.svg`: preserved refinement studies.
- `logo-tests.html`: size ladder, backgrounds, monochrome, blur, mirroring and interface contexts.
- `presentation.html`: brand presentation and application mockups.

## Usage

Use teal on white or pale surfaces, and lime or white on navy. Keep at least one stroke width (48 units, about one fifth of the symbol canvas) clear around the visible symbol. Minimum symbol size: 16 px; use 24 px or larger for primary UI branding. Minimum horizontal lockup width: 120 px. Keep the original proportions, do not add effects, and do not place lime artwork on white.

Figtree is served locally as a variable font, licensed under the SIL Open Font License; the license is included in `frontend/public/fonts/OFL.txt`. The UI uses live text for accessibility; the downloadable lockups use outlines. UI colors and both themes come from the supplied CSS palette in `frontend/src/index.css`.

## Research and verification

Mobbin references: [Mixpanel metric grouping](https://mobbin.com/screens/1a7d8d86-f0e8-456a-a60c-65c6eb13a252), [Linear report hierarchy](https://mobbin.com/screens/cef36326-d8ec-4c6f-acd4-a9f1e1060d33), and [Linear navigation and detail structure](https://mobbin.com/screens/beb9d6b3-ec34-46d7-9332-320fcb32a338). Reference logos in the installed library were studied for construction, not copied.

Exploration also considered a split lens, connected blocks, a folded ribbon, a stepped S, a signal notch, a paired bracket, an evidence aperture, a waypoint and a custom wordmark. The first three were built; Signal S offered the clearest initial and smallest-size silhouette. V2 increases the visible footprint and opens the inner curves. Two rounds were rendered and inspected, followed by in-app desktop/mobile and light/dark review. The symbol and favicon pass the installed SVG audit without warnings. The outlined Figtree lettering triggers expected angle and complexity advisories; its original type geometry is preserved.

Trademark clearance and print-production color matching have not been performed. The digital masters use the requested RGB/HEX palette.
